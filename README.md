## 📌 Project Overview

Designed and delivered a **global Enterprise Endpoint Detection & Response (EDR) transformation** by deploying Microsoft Defender for Endpoint and CrowdStrike Falcon across enterprise Windows, Linux, and macOS environments.

---

## 🎯 Project Objectives

- Standardize endpoint security globally
- Improve enterprise threat detection
- Strengthen endpoint visibility
- Reduce false positives
- Enhance SOC operational readiness
